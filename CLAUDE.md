This repository is wired to an **AgentWorks** cluster. The `agentworks` MCP
server is connected in this workspace — use it to discover models / tools / MCP
integrations / capability policies, validate and deploy agents, and inspect
runs, sessions, and runtimes. Prefer the MCP tools over guessing.

**Read `.agentworks/context.md`** for the builder contract,
`.agentworks/bundle/cluster-context.json` for live catalog and affordances, and
worked examples in `.agentworks/examples/`.

Check `.agentworks/bundle/manifest.json` first. If `include` is
`embedded-fallback`, authenticate and rerun `agentworks builder init --out .`
before resource work; its empty cluster context is offline setup state, not a
live authorization result.

Key commands:
- `agentworks auth login` — authenticate (mints a long-lived Personal Access Token)
- `agentworks agent validate -f <spec>` — validate an agent spec
- `agentworks agent deploy` — deploy a validated agent
- `agentworks skill pack|import|audit` — manage governed portable skills
- `agentworks builder init --out .` — atomically refresh the verified live bundle

Do not edit the lines between the AGENTWORKS markers — they are regenerated by
`agentworks builder init`.
